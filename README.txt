BLUFF-HAUS - deploy su Vercel
1) Vai su vercel.com > Add New > Project (oppure usa "vercel" da terminale)
2) Carica questa cartella (index.html, manifest.webmanifest, vercel.json, icons/)
3) Framework: "Other", nessun build command, output directory vuota
4) Deploy. L'online usa PeerJS (CDN) e funziona solo su HTTPS: Vercel lo fornisce.
